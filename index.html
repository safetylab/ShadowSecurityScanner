What is ShadowSecurityScanner?

It is a modern network vulnerability scanner: point it at a host or IP range, and it discovers open services, identifies each product and version over the network, and reports the CVEs that affect them — with exploited-in-the-wild vulnerabilities surfaced first. No server to deploy, no license keys, no cloud account, no telemetry.

Features

Everything you need for fast, private, prioritized vulnerability assessment.

Version-bounded CVE detection

A curated pack of 6,900+ CVEs across 100+ products (web servers, databases, VPNs, message brokers, ICS and more), matched against detected versions to cut false positives.

KEV & EPSS prioritization

Every finding is annotated with CISA Known Exploited Vulnerabilities status and FIRST EPSS exploit probability, so you triage what attackers actually use.

Agentless & read-only

Detection observes banners, versions and exposed endpoints — never sends exploits. Safe to run against production; nothing is installed on targets.

Deep protocol coverage

HTTP/TLS, SMB, DNS, SNMP, LDAP, Kerberos, databases (MySQL, PostgreSQL, MongoDB, Redis), message queues, and ICS/OT protocols — via a plugin architecture.

SBOM & STIX export

Export findings and detected components as CycloneDX SBOM or STIX for your inventory, ticketing and threat-intel pipelines.

Compliance mapping

Findings map to PCI DSS, CIS and NIST controls, so a scan turns straight into audit-ready evidence.

Always-fresh intel

The CVE, KEV and EPSS data is refreshed automatically from NVD, CISA and FIRST — new exploited vulnerabilities show up without waiting for an app update.

Single cross-platform binary

One fast desktop app for Windows (x64/arm64), Linux (x64/arm64) and macOS. No dependencies, no runtime to install.

Frequently asked questions

What is ShadowSecurityScanner?

A free, self-hosted network vulnerability scanner. It fingerprints services on your network, matches their versions against a curated CVE database, and prioritizes findings using CISA KEV and FIRST EPSS. It runs as a single cross-platform desktop app on Windows, Linux and macOS.

Is ShadowSecurityScanner free?

Yes — free to download and use, with MIT-licensed binaries for Windows, Linux and macOS. No paid tier, no seat licensing, no cloud account required.

How is it different from Nessus or OpenVAS?

It is a lightweight, self-hosted single binary with no server to stand up, no license keys and no telemetry. Detection is read-only and agentless, and every finding is prioritized with CISA KEV and EPSS so you triage exploited vulnerabilities first.

Is it safe to run against production systems?

Yes. Detection is read-only and non-destructive: it observes banners, versions and exposed endpoints rather than sending exploits, and never writes, executes or retrieves sensitive data beyond a benign confirmation marker.

How many vulnerabilities can it detect?

The bundled version-bounded CVE pack covers more than 6,900 CVEs across 100+ products and services, refreshed automatically from NVD, CISA KEV and FIRST EPSS, plus named high-profile CVEs and exposed-service checks.

Does it need an agent on the targets?

No. Scanning is agentless and network-based — you point it at a host or range and it identifies services and vulnerabilities over the network.
